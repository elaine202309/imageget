# ImageGet — Website

Marketing website for **ImageGet - Downloader From Web**, an iOS app for saving images from web pages in one tap.

## Pages

- `index.html` — landing page (hero, features, pricing, FAQ)
- `privacy.html` — privacy policy
- `terms.html` — terms of service

## Structure

- `images/` — app icon and the screenshots/crops used by the site

## Deployment

Hosted with GitHub Pages.
