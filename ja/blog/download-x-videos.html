X(Twitter)の動画をダウンロードする方法

2026年9月29日 · ImageGet チーム

X の動画をオフラインで見たい、あとで共有したい——ImageGet なら簡単です。投稿のリンクを貼り付けると、アプリが動画を解析し、写真ライブラリへそのままダウンロードできます。画面収録もサードパーティ製ツールも不要です。X(Twitter)の動画をダウンロードする手順を紹介します。

ImageGet を無料でダウンロード — X の動画をワンタップで保存。

ImageGetをダウンロード

ステップ 1: ImageGet を開いて Video Download をタップ

ImageGet を開きます。ホーム画面で Video Download をタップしてください。動画関連のツールはここにまとまっています。

ステップ 2: X (Twitter) Download を選ぶ

続いて X (Twitter) Download をタップします。ImageGet が X モードに切り替わり、リンクの入力待ちになります。サムネイルではなく、動画そのものを取得できます。

ステップ 3: 投稿のリンクをコピー

X アプリを開き、保存したい動画がある投稿を探します。投稿の下にある 共有 ボタンをタップし、リンクをコピー を選びます。パソコンのブラウザなら、投稿を開いてアドレスバーの URL をコピーしてください。

ステップ 4: ImageGet に貼り付ける

投稿のリンクを ImageGet に貼り付けます。アプリが動画を自動で解析するので、検索も待ち時間もありません。すぐに動画が表示され、ダウンロードできる状態になります。

ステップ 5: 動画をダウンロード

X の投稿では複数の MP4 が用意されていることがよくあります。ImageGet は解像度とファイルサイズを並べて表示するので、希望の画質を選んで Download をタップします。動画は音声付きで写真ライブラリに保存されます。X を開かなくても、オフラインでも、いつでも見返せます。

X の動画ダウンロードのヒント

  • 無料ダウンロード — 無料プランには動画 3 回分のダウンロードがあり、X(Twitter)の動画・YouTube Shorts・Facebook Reels で共通です。無制限にするには Premium にアップグレードしてください。
  • 解像度を選べる — X は複数の MP4 を用意していることが多く、それぞれ解像度とファイルサイズが表示されるので、画質と容量のバランスを取れます。
  • 画面収録は不要 — ImageGet は動画を直接ダウンロードするため、録画し直すことによる画質劣化がありません。
  • 投稿リンクでも使える — x.com/…/status/… のような URL もそのまま貼り付けられます。
