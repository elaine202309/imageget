iPhone に HD・4K 壁紙をあらゆるサイトから保存する方法

壁紙はブラウザでは完璧に見えるのに、ロック画面ではひどく見えることがあります。これはサイトが解像度を偽っていたからではなく、iPhone が保存した画像がページに表示されていたプレビューで、その背後にある大きなファイルではなかったからです。ImageGet はページが参照している画像をすべて集めるので、実際のサイズを確認して一番大きいものを残し、写真ライブラリに保存できます。

壁紙が「正しく保存するのが一番難しい画像」である理由

壁紙サイトはフル解像度のファイルを守るように作られています。右クリックや長押しはたいてい無効化され、ダウンロードボタンは別のページを先に開くことが多く、画面に表示されている画像は元画像を縮小したコピーであることもよくあります。そのコピーを保存してしまうと、Safari では鮮明なのに他のどこでもぼやけた壁紙になります。

2つ目の問題は、1つのページが1つのファイルだけを参照していることはほとんどないという点です。サムネイル、いくつかの中間サイズ、ときには別の形で切り抜かれたモバイル版、そして普通の img タグではなく CSS の背景として指定された画像も参照しています。どのバージョンを手にするかは、どこをタップするかで変わります。

iPhone における「HD」と「4K」の本当の意味

大事な数字は2つあり、そのうちみんなが口にするのは片方だけです。

  • ピクセル数。 最近の iPhone の画面は横 1170〜1320 ピクセル、縦 2530〜2870 ピクセルほどです。この解像度以上の壁紙は鮮明に見えますが、それより小さいと iOS が拡大してディテールが失われます。
  • アスペクト比。 iPhone の画面はほぼ 9:19.5 の縦長です。一方、4K の壁紙は 3840 × 2160 で 16:9 の横長。フル HD の4倍のピクセル数がありますが、設定時に半分以上が切り取られるため、スマホの壁紙としては向いていません。

つまり「4K」という表示はファイルが大きいことしか示しておらず、自分のスマホに合うかは分かりません。壁紙サイトではまずスマホ用・縦長のコーナーを探し、そのうえでピクセル数を確認してください。縦長であることと十分なピクセル数がそろって初めて、壁紙は鮮明になります。

ステップ1：壁紙ページのリンクをコピーする

コピーするのは壁紙が表示されているページの URL です。画像ファイルの URL でも、サイトのダウンロードボタンでもありません。ImageGet はページそのものを読み込みますが、画像のすべてのバージョンはそこにあります。

ステップ2：ImageGet に貼り付けて Go をタップ

ImageGet を開いてリンクを貼り、Go をタップします。ImageGet はページを読み込み、参照されている画像をすべて集めます。プレビュー、サーバーが配信している各サイズ、ページの背景として指定された画像まで含まれます。当てずっぽうの1枚ではなく、セット全体をグリッドで確認できます。

ステップ3：解像度で絞り込み、一番大きいものを残す

このステップが壁紙の鮮明さを決めます。Smart Filtering をオンにして最小サイズを設定すると、ImageGet はサムネイルやプレビュー用のコピーを外し、各画像のフル解像度版だけを残します。同じ画像が複数のサイズで配信されているページでも、絞り込めば大きい方を保存できます。

画像をタップして全画面で開き、2本指でズームしてみてください。その倍率なら、400 px のプレビューと 3000 px の元画像の違いはひと目で分かります。保存する前に確認しましょう。

ステップ4：写真ライブラリに保存する

Save All をタップすると、画像はサイトが公開している解像度のまま写真ライブラリに入ります。途中で拡大されたり再圧縮されたりすることはありません。サイトに本物の 4K があれば、そのファイルがそのまま手に入ります。

ダウンロードしたものは ImageGet の Local Folder にも保存した日付ごとに残ります。候補をいくつか見比べているときは、ここに戻ってください。フルサイズのバージョンは、どれにするか決めるまでそこに残っています。

ステップ5：iOS で壁紙に設定する

保存した画像を写真アプリで開き、共有ボタンから壁紙に設定を選びます。または「設定」→「壁紙」→「新しい壁紙を追加」→「写真」の順に進みます。ここで知っておきたいことが2つあります。

  • iOS は拡大します。 ロック画面は画面いっぱいに表示するために画像を拡大・切り抜きします。すでに画面と同じアスペクト比になっている画像が、最も失うものが少なくなります。
  • 視差効果をオフにすると、壁紙がアイコンの下をずれるように見える現象を防げます。この視差効果は端末を傾けると画像を動かし、端もさらに切り取ります。

それでも柔らかく見えるなら、元のファイルが小さかった可能性が高いです。元のページに戻って、ピクセル数が一番多いバージョンを探してください。

壁紙選びのクイックチェック

  • 横長ではなく縦長。最近の iPhone ならおよそ 9:19.5。
  • 画面以上のピクセル数。目安は 1170 × 2530 以上。
  • 大事な部分が中央付近にあること。切り抜きで失われません。
  • iPhone がそのまま開ける形式。JPEG、PNG、HEIC、WebP。

FAQ

iPhone に 4K の壁紙をダウンロードするには？

壁紙があるページのリンクをコピーして ImageGet に貼り、Go をタップしたらサイズで絞り込んで、サイトが配信している一番大きいバージョンを残します。Save All をタップすれば、フル解像度のファイルが写真ライブラリに入り、壁紙として設定できます。

保存した壁紙が iPhone でぼやけるのはなぜ？

保存されたファイルが、サイトの背後にある元画像ではなく、ページに表示されていたプレビューだったことがほとんどです。ImageGet はページが参照しているすべてのサイズを集めるので、解像度で絞り込んでサムネイルではなく大きいバージョンを保存できます。

iPhone の壁紙にはどのくらいの解像度が必要？

最近の iPhone の画面は横 1170〜1320 ピクセル、縦 2530〜2870 ピクセルほどで、アスペクト比はおよそ 9:19.5 です。このピクセル数以上の縦長画像なら鮮明に見えますが、それより少ないと iOS が拡大してぼやけます。

ImageGet で壁紙を無料でダウンロードできますか？

はい。無料プランには Web 画像のダウンロードが2回分含まれ、Premium では回数制限なく保存できます。

右クリックを禁止しているサイトでも使えますか？

はい。ImageGet はタップではなくページを読み込むので、長押しや右クリックを無効にしているサイトでも問題ありません。ページにある画像をそのまま集めます。
